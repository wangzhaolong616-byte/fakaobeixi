# 律灯 · 法考智能备考系统

一个可以每天打开、持续使用、点击交互、追踪进度的备考系统。不是 Word，不是 PDF，不是一次性答案。

**目标年度：2027 年国家统一法律职业资格考试。**

## 一、怎么打开（本地）

双击 `index.html` 即可（Chrome / Edge / 任何现代浏览器）。

- 无需安装、无需联网、无需服务器。
- 学习记录保存在浏览器本地（localStorage），下次打开自动继续。
- 手机浏览器也能用（已做响应式适配 + iPhone 刘海屏安全区）。
- 换电脑或清理浏览器数据会丢失记录 —— 请定期用「设置 → 导出学习记录」备份。

首次打开会直接进入 **法考入学诊断**（24 题，覆盖 8 个板块）。做完才生成个人计划。
之后每次打开会**回到你上次停留的页面**。

### 一个必须知道的事实：官方不再公布真题

**2018 年法考改革后，司法部不再公布真题和答案**（2025 年进一步下架了历史数据）。市面上所有标称「历年真题」的材料，本质上都是**考生回忆版**或**机构整理版**，存在记忆偏差和改编。

本系统对此的处理方式：题库中每一道题都带来源标签，**已导入 300 道客观题回忆版（2019 年卷一 100 题 + 卷二 100 题；2020 年卷一 100 题），官方真题仍为 0 道**，界面上从不把回忆版或模拟题说成真题。详见第四节。

**年份覆盖**

| 年份 | 试卷 | 题量 | 来源 |
|---|---|---|---|
| 2019 | 试卷一 | 100（1—100 完整） | 233 网校整理回忆版 |
| 2019 | 试卷二 | 100（1—100 完整） | 233 网校整理回忆版 |
| 2020 | 试卷一 | 100（1—100 完整） | 233 网校整理回忆版 |

两个年份的同一份卷子可以直接横向比对，考频统计的参考价值明显高于单一年份。

> 关于 300 道回忆版：题干与答案来自公开题库站点的考生回忆整理，每题均标注 `srcLevel = 回忆版`，界面统一显示「（回忆版）」。凡涉及 2021 年以后修订法律（立法法、行政复议法、行政处罚法、治安管理处罚法、民事诉讼法、仲裁法等）的题目，**条号已逐条比对官方文本核对**，答案按当年法律记录，并在 `timeEffect` 字段中写明现行法下是否变化。每题均有该字段，其中 204 道为逐题人工判断、96 道为按「年份 + 板块」规则补的通用警示。

## 四、这个系统最重要的一条原则：不伪造数据

法考备考圈最大的坑不是「学不会」，而是**学到假东西**。所以本系统做了五件别处很少做的事。

### 1. 题目来源分级，绝不冒充真题

每道题都带来源标签：`官方真题` / `机构整理` / `回忆版` / `模拟`。

**当前题库 657 道 = 自编模拟题 357 道 + 2019、2020 两年客观题回忆版 300 道。官方真题 0 道、机构整理 0 道。**

300 道回忆版中，**2019 年卷一 100 题（1—100）、2019 年卷二 100 题（1—100）、2020 年卷一 100 题（1—100）均为全卷覆盖**。所有真题均带「（回忆版）」标识，不冒充官方真题。

### 2. 措辞也受这条原则约束（这一条很多系统做不到）

不只是数据要诚实，**界面上的话也必须诚实**。

系统里有一个 `bankNature()` 函数，实时判定题库的真实构成。界面文案能不能出现「真题」二字，完全由它决定：

- 题库里**真的存在**官方真题/机构整理/回忆版 → 才允许用「真题」描述题目
- 题库全是模拟题 → 一律称「题目」或「模拟题」

导入真题数据后，措辞与考频统计会**自动切换**——这正是已经发生的事：导入 300 道回忆版后，界面已自动出现「历年真题训练」「只做历年真题」等入口，同时每一处与真题相关的文案都带上了「（回忆版）」与来源声明。

### 3. 考频次数由题库自动统计，且只统计真题

考频引擎统计来源为「官方真题」「机构整理」「回忆版」的题目（回忆版纳入统计，但同时显式声明其证据等级低于官方真题）。当前 **300 道回忆版已计入考频**，界面显示「考频基于 300 道回忆版真题统计。司法部自 2018 年改革后不再公布真题与答案，因此不存在官方考频数据」。

知识节点里**一个硬编码的考频数字都没有** —— 宁可显示「未统计」，也不给假数字。

与之相对，「★ 考试重要度」是**专业初判**（依据命题规律、大纲地位、综合命题价值、主观题价值），界面上明确标注了它是初判而非统计结果。

### 4. 不承诺通过概率，不做分数预测

系统只呈现可量化的学习数据（覆盖率、正确率、掌握度、得分率）。

- 模拟考试结果会按 180/300 等比折算一个「合格线参考」，但明确说明这是**模拟题上的表现**，不能等同于真实水平。
- 主观题自评只给「档位判断」（高质量档 / 合格档 / 最低得分档 / 需重学），**不给分数**——因为主观题得分取决于阅卷老师对表述、逻辑、法言法语的综合判断，任何机器给分都是不负责任的。

### 5. 新法逐条核验，并公开纠正错误说法

新法专区 15 条全部标注了结论等级（官方已确认 / 官方来源可推知 / 二手来源未核实 / 查无实据 / 与官方法条矛盾）与证据来源。

核验过程中纠正了 **5 条流传较广的错误说法**，其中两条值得特别记住：

- ❌「治安管理处罚法修订后追诉时效由 6 个月延长至 1 年」
  → **与官方法条矛盾**。官方文本仍为「违反治安管理行为在六个月以内没有被公安机关发现的，不再处罚」。这条极可能被命题人用来设置干扰项。
- ❌「2026 年法考大纲新增『海外管辖豁免』科目」
  → **查无实据**。司法部公告原文表述为「保持各考查科目知识点及考查要求总体稳定」，未提及新增科目。

另外三条（民诉法新增文书提出命令、政务处分法纳入考查范围、反外国不当域外管辖条例施行日）也已分别标注为「未核实」或「表述不准确」。

### 6. 时间效力字段

每题都带 `timeEffect` 字段。凡涉及新旧法差异的（如民法典把保证方式推定从「连带责任保证」改为「一般保证」、新公司法五年缴足出资与董事作为清算义务人、股东失权制度、民法典担保制度解释确立的让与担保规则），都会明确提示：**这道题的答案是否因新法而变化**。

**⚠️ 新法处理硬规则：「提示」不等于「核对」。** 凡涉及新修订法律，必须抓官方文本（npc.gov.cn / gov.cn）逐条核对条号与规则，把条号写死成确定值；**不允许用「条文编号可能变化，请以修订后文本为准」这类表述代替核对**——那等于把核实责任推给使用者，而且题目答案本身可能是错的。

已按此规则核验并修正的实例：《仲裁法》2025 年修订（2026-03-01 施行）把**撤销裁决的申请期限由旧法第 59 条的「6 个月」缩短为新法第 72 条的「3 个月」**。这是实质变化，题库里原本按「6 个月」出的题与答案已全部改正。同类条号变化：仲裁协议无效 17→28、效力异议 20→31、撤销事由 58→71、不予执行 63→76；全法「仲裁委员会」统一改称「仲裁机构」。

## 五、两个必须分开看的指标

| 指标 | 含义 | 来源 |
|---|---|---|
| ★★★★★ | **考试重要度** | 专业初判 |
| 78 / 100 | **你的个人掌握度** | 你的真实答题记录（含遗忘衰减） |

可能出现「★★★★★ 但掌握度 42」—— 意思是「超级重点，但你很差」，这类内容自动进入最高优先级。

优先级算法：

```
优先级 = 考试重要度 × 板块权重 × 掌握度缺口 × 遗忘紧急度 × 主观题价值
```

## 六、怎么扩充（这是「持续使用」的关键）

数据越填越准，判断越准。

### 导入真题

「设置 → 导入题目」粘贴 JSON 数组，数据结构：

```json
[{
  "id": "Q9001",
  "srcLevel": "官方真题",
  "src": "2024年法考客观题（回忆整理）",
  "year": 2024,
  "stage": "客观题",
  "paper": "试卷二",
  "no": 15,
  "sec": "民法",
  "k": "MF-10",
  "type": "单选",
  "stem": "题干……",
  "options": ["A……", "B……", "C……", "D……"],
  "answer": ["C"],
  "difficulty": 4,
  "trap": "命题陷阱说明",
  "statute": "民法典第563条",
  "correctWhy": "正确选项为什么对",
  "wrongWhy": {"A": "A 为什么错", "B": "B 为什么错", "D": "D 为什么错"},
  "related": ["MF-11"],
  "timeEffect": "旧题答案是否因新法变化"
}]
```

`k` 字段填知识节点 ID（在「知识体系」中可查，如 `MF-10`、`XZF-04`）。填对后，该题会自动挂到对应知识点下，考频统计随即生效。

**注意两个字段的格式**：
- `options` 是**字符串数组**（不要写成 `{key, label}` 对象）
- `answer` 是**字母数组**（如 `["C"]` 或 `["A","C","D"]`）

> ⚠️ 导入真题时**请如实填写 `srcLevel`**。把模拟题标成真题，会直接破坏整个系统的判断依据，也会让界面上的「真题」措辞失去意义。

### 补充知识节点

编辑 `js/data-knowledge.js`，往 `nodes` 数组里加对象即可。字段说明见文件顶部注释。`tier` 字段：A = 六层完整讲解，B = 核心结论 + 陷阱，C = 节点占位。

也可以不改动主文件，新建 `js/patch-k-xxx.js` 写补丁（参考现有 `patch-k-*.js` 的写法），在 `index.html` 里按顺序引入即可。

## 七、已知边界（如实说明）

1. **题库 657 道 = 自编模拟题 357 道 + 客观题回忆版 300 道（2019 卷一/卷二 + 2020 卷一）。** 按官方题型结构组「标准卷」（100 题）与「双卷连考」（200 题）已可行。回忆版真题存在记忆偏差，且**答案按当年法律记录**；凡遇新法修订可能影响结论的题目，都在该题解析的「时间效力」栏写明了现行法下的差异（例如 2019 卷一第 53 题：新《行政复议法》把复议管辖统一到本级人民政府，按现行法答案由 BC 变为 BCD）。
   **已覆盖两个年份（2019、2020），可做初步的跨年比对；但两年份仍不足以支撑「命题趋势」的稳健判断，结论请谨慎。**
   **来源层面的两处如实说明**：① 233 网校整理的「2019 年试卷一」这一份资料**本身不含刑事诉讼法题目**（该站的整理版如此，非本系统筛选所致），因此 2019 卷一在刑诉板块为 0 题；② 233 网校的 2020 年试卷二系列**只公开到第 55 题**，不足以构成完整试卷，故本系统**未收录**，待来源补全后再导入。
2. **知识节点 156 个**覆盖八大板块主干，但不等同于大纲全部知识点。分三层：A 层（完整讲解，81 个）、B 层（核心结论 + 陷阱，75 个）、C 层（占位，**已归零**）。

## 十、发布与同步

站点同时存在于**三个位置**，改动后需要保持三者一致：

| 位置 | 角色 |
|---|---|
| 本地 `法考备考系统/` | 开发源，代码以此为准 |
| GitHub `wangzhaolong616-byte/fakaobeixi` | 源码仓库 + Pages 发布源 |
| 内置发布（`dist/` 目录） | 国内访问镜像 |

发布流程：

```bash
# 1. 生成纯净发布目录（只含 index.html / favicon.svg / js/）
bash make-dist.sh

# 2. 提交并推送源码
git add -A && git commit -m "..." && git push origin main
#    → GitHub Pages 会在 1~3 分钟后自动重建

# 3. 重新发布内置镜像（dist/ 目录）
```

**验收口径**：本地 → 远端仓库比内容（sha256），远端仓库 → 线上站点下载比对。注意 GitHub Pages 有 1~3 分钟构建延迟，且大文件下载偶有截断，比对前应确认字节数一致。

**已排除在仓库外**（见 `.gitignore`）：`import/*.html`、`import/y1/`（抓取自第三方站点的原始页面，仅作本地解析原料）、`shot-*.png`（测试截图）、`dist/`（构建产物）。
